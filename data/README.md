# data/ — local only

Put the dataset files here on your own computer. Everything in this folder except this
file is ignored by Git.

- `emophone/` — EmoPhone waves D-1, D-2, D-3 (Harvard Dataverse, doi:10.7910/DVN/QGRVU8).
  Not to be redistributed.
- `uci/` — UC Irvine dataset (Dryad, doi:10.7280/D1WH6T).
- `lifesnaps/` — LifeSnaps (Zenodo 7229547, CC BY 4.0), optional external test only
  (`docs/PROJECT.md` §5.5). Never committed.
